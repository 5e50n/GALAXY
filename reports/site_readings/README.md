# قراءات الموقع — بيانات ORBIT

كل الأرقام هنا طلعت من **كود الموقع نفسه وهو شغّال بالمتصفح**: نفس النموذج ونفس بيانات ناسا ونفس الحسابات الفلكية. يعني الرقم بالملف هو نفس الرقم اللي يشوفه الزائر.

- وقت التوليد: موجود بـ `generated.json` (بتوقيت UTC).
- **"الليلة"** بالملفات 03 و04 تعني الليلة اللي بعد وقت التوليد، بالطقس والقمر الحقيقيين. إذا تريد قراءات ليلة ثانية، أعد التوليد.
- لإعادة التوليد:
  ```bash
  npm run dev
  node tools/export_site_readings.mjs
  ```
  تحتاج Google Chrome واتصال إنترنت، ويأخذ تقريباً 4 دقائق بسبب حد طلبات خدمة الارتفاعات.
- الملفات CSV بترميز UTF-8 مع BOM، حتى يفتحها Excel بالعربي بشكل صحيح.

## الملفات

### 01_sites_sky_quality.csv — جودة السماء لكل موقع (13 موقع)
هذه الأرقام تمثل السماء بظروف مرجعية: ليلة صافية بلا قمر، منتصف الليل.

| العمود | المعنى |
|---|---|
| `engine` | النموذج المستخدم. v2 = ناسا Black Marble 2024 (داخل العراق)، v1 = ناسا GIBS 2016 (خارجه) |
| `ai_sqm` | **توقع الذكاء الاصطناعي** لسطوع السماء (mag/arcsec²). الرقم الأكبر يعني سماء أظلم |
| `uncertainty_sqm` | الخطأ النموذجي للتوقع (±) |
| `bortle`, `bortle_name` | صنف بورتل: 1 أظلم سماء، 9 وسط مدينة |
| `nelm` | أخفت نجم يُرى بالعين المجردة (قدر) |
| `naked_eye_stars` | عدد النجوم المرئية بالعين المجردة تقريباً |
| `satellite_only_sqm` | التقدير من صورة القمر الصناعي وحدها، بدون ذكاء اصطناعي، للمقارنة |
| `v1_sqm` | توقع النموذج القديم v1 لنفس المكان، للمقارنة |
| `radiance_*` | إشعاع ناسا 2024 (nW/cm²/sr) بالموقع وضمن الحلقات: 10 كم، 10–50 كم، 50–160 كم |
| `skyglow_index` | مؤشر توهج المدن المحيطة، محسوب بقانون ووكر (المسافة^−2.5) |
| `darkest_direction` / `city_glow_direction` | أظلم اتجاه للرصد / اتجاه قبة ضوء المدينة |
| `tonight_*` | الليلة الحقيقية: الوقت، الغيوم (%)، إضاءة القمر (%)، السماء المتوقعة، وعدد الأهداف العميقة المرئية |

### 02_iraq_grid_sky_quality.csv — خريطة العراق (1,443 نقطة كل 0.25°)
- أعمدته: `lat`, `lon`, `elevation_m`, `ai_sqm`, `bortle`, `nelm`, `radiance_point`.
- تغطي العراق وأطراف الدول المجاورة. النقاط كلها ضمن تغطية النموذج v2.
- تنفع لرسم خريطة، أو لإيجاد أظلم الأماكن القريبة من أي مدينة.

### 03_tonight_telescope_targets.csv — أهداف التلسكوب الليلة
لكل موقع: السدم والمجرات والعناقيد اللي فوق 20° ارتفاع. الأعمدة:
- `effective_sqm`: السماء الفعلية باتجاه الهدف، بعد حساب القمر وقبة المدينة والأفق.
- `needs_sqm`: السماء اللي يحتاجها الهدف.
- `visible`: هل الهدف يُرى.

### 04_tonight_planets_by_instrument.csv — الكواكب الليلة × 4 أدوات
الأدوات هي: `eye` (العين)، `bino` (دربيل 50 مم)، `scope114` (تلسكوب 114 مم)، `scope200` (تلسكوب 200 مم).

| العمود | المعنى |
|---|---|
| `up_tonight` | هل يرتفع فوق 10° بالليل |
| `best_time_utc`, `altitude_deg`, `direction` | أفضل وقت للرصد، والارتفاع، والاتجاه |
| `magnitude` | اللمعان. الرقم الأصغر يعني أسطع |
| `sky_at_best_time` | سطوع السماء وقت الرصد لهذا الجسم، بالقمر والغيوم الحقيقية لتلك الساعة |
| `sees_body` / `sees_goal` | هل يُرى الجسم نفسه، وهل يُرى الهدف (مثلاً أقمار المشتري) |
| `required_sqm` | السماء المطلوبة لرؤية الهدف. رقم أقل من 16 يعني أي سماء تكفي. `impossible` يعني يحتاج سماء أظلم من أي سماء طبيعية على الأرض (~22)، فما يُرى بهذه الأداة |
| `light_cut_needed_pct` | نسبة تقليل الإضاءة اللازمة وقت الرصد، يحسبها نموذج الذكاء الاصطناعي. `unreachable` يعني حتى إطفاء كل الأضواء ما يكفي (غالباً بسبب القمر) |

**ملاحظة:** نسبة التقليل تُحسب حتى للكوكب اللي تحت الأفق. الأهم شوف `up_tonight` أول.

### 05_lighting_scenarios.csv — سيناريوهات الإضاءة (محاكي "ماذا لو")
- `now_sqm`: السماء الحالية.
- `after_default_policy_sqm`: السماء بعد السياسة الافتراضية بالمحاكي. السياسة: إطفاء 30% من إنارة الزينة، توجيه 60% من المصابيح للأسفل، تخفيت 35%، إطفاء ليلي، ومصابيح دافئة. `default_policy_light_factor` هو نسبة الضوء المتبقي بعد السياسة.
- `all_lights_off_sqm`: السماء لو انطفت كل الأضواء الصناعية، يعني السماء الطبيعية حسب النموذج.
- `cut_for_bortle6_pct` … `cut_for_bortle3_pct`: نسبة التقليل اللازمة للوصول لكل صنف بورتل.

### 06_model_metrics.json — دقة النموذجين v1 و v2
يحتوي الدقة المقاسة على مناطق ما شافها النموذج، وأهمية كل ميزة بالتوقع.

## حدود البيانات (بصراحة)
- **هذه توقعات نموذج، مو قياسات.** الخطأ النموذجي ±0.5 تقريباً، وبمراكز المدن الكبيرة ±1.3.
- **داخل المدن الكبيرة النموذج يوصل لحده الأدنى تقريباً (~17.5).** لهذا بغداد والبصرة والموصل أرقامها متقاربة، ونسب التحسين بالمحاكي تطلع صغيرة هناك.
- **معاملات المحاكي افتراضات منشورة بالموقع، مو قياسات محلية.** مثلاً: إنارة الزينة ≈20% من ضوء المدينة.
