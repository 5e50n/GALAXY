# 🛰️ Team Galaxy — Dark Sky & Light Pollution AI

**Team Galaxy · ASI Orbit Hackathon 2026 · Challenge 1: Light Pollution & Astronomical Observation**

An AI trained on real ground measurements corrects what NASA satellites miss about the night sky, then:
1. **Predicts real sky quality** anywhere on the map (click any point).
2. **Guides your telescope tonight**: where the city glow is, where the moon is, what's worth pointing at — and a **live phone compass** that turns you towards it.
3. **What-if simulator**: responsible-lighting policies go back into the model to predict the new sky.
4. **Planets & calibration**: where every planet is tonight (NASA JPL orbital elements, ≤0.1° vs JPL Horizons), what your eye/binoculars/telescope will show from this sky, and how much the lights must be cut (via the AI model) to see faint targets — with a 3D telescope view.
5. **Community**: an observations gallery, a beginner's guide, and a way to join.

## Results (tested on regions the model never saw)
| | Satellite only | **ORBIT AI** |
|---|---|---|
| MAE | 0.81 mag/arcsec² | **0.61** (−25.7%) |
| Within ±0.5 mag | 42% | **62%** |
| Bortle class within ±1 | 79% | **84%** |
| R² | 0.48 | 0.63 |

Inside Iraq the site uses **model v2** (NASA Black Marble VNP46A4 2024 calibrated radiance): on the same rows MAE 0.556 → **0.542**, Bortle ±1 **87%**, and agreement with Middle-East observers (Spearman) 0.20 → **0.38**. See [reports/v1_vs_v2.json](reports/v1_vs_v2.json) and [reports/feasibility_study.md](reports/feasibility_study.md).

Full report with figures and tables: [reports/README.md](reports/README.md) · How to train: [ml/README.md](ml/README.md)

## Layout
```
index.html, style.css      Website (Vite)
src/main.js                App wiring
src/modules/
  skyModel.js              Runs the trained model in the browser (v1, global)
  skyModelV2.js            Model v2: NASA Black Marble 2024 radiance raster for Iraq
  planets.js               Planet ephemeris (JPL), visibility per instrument, light cut via the model
  planetViewer.js          3D telescope view (Three.js, loaded on demand; from the team's prototype)
  liveCompass.js           Live phone compass (orientation sensor, true-north corrected) → points to targets
  viirs.js                 NASA VIIRS light features (same as training)
  astro.js                 Sun/Moon (same as training)
  skyMath.js               NELM, Bortle, visible stars
  telescopeGuide.js        Tonight's targets & best direction
  darkSkySimulator.js      What-if lighting policies → model
  sites.js, nasaApi.js, satelliteTracker.js, i18n.js (Arabic default)
public/model/sky_model.json   Trained model (generated by ml/03_train.py)
public/model/sky_model_v2.json, iraq_radiance_2024.png   Model v2 (ml/06_blackmarble_v2.py)
public/data/observations.json Photo results (generated by ml/04_analyze_photos.py)
public/data/observation_places.json  Illustrative Nineveh gallery locations (ml/07_display_places.py)
tools/export_site_readings.mjs       Exports everything the site computes → reports/site_readings/ (npm run export-readings)
ml/                        Data, training, photo analysis (Python)
reports/                   Model report, figures, tables, photo results (generated)
docs/                      Hackathon briefs + UI snippets
```
